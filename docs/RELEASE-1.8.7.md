感谢您使用 HyperPGuard。

这一版修「行为库状态」弹窗里两个按钮的显示问题，都是 1.8.6 遗留的。

## 修复

- **文字颜色**：1.8.6 里「清空行为库」被对话框的统一样式刷成了正文色（看起来是黑的），现在与「刷新」同为主题蓝
- **按钮排布**：改为竖排——清空行为库在上（主操作），刷新在下
- **按压范围**：从铺满整行改为「文字 + 左右 24dp」，按下去只在文字附近变色，不再整条发灰

## 说明

- 清空逻辑（删除范围、root 要求、二次确认措辞）与 1.8.5 / 1.8.6 完全一致，没有功能变化
- 只改这一个弹窗的布局与配色

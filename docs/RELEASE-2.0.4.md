感谢您使用 HyperPGuard。

这一版修三处使用中会遇到的问题，都是「看起来没反应」或「显示不对」这一类。

## 修复

- **底栏单击偶尔不切页**：点某一页时胶囊会走一段又弹回、页面停在原页。原因有两个：松手时读的是胶囊动画目标值，而这个值在按住期间可能被上一段页面吸附动画改掉；另外底栏触摸区只覆盖了胶囊高度，点在下沿那 8dp 里完全没有响应。现在松手按手指落点所在的格切页，按住期间不让吸附动画改选中态，触摸区补满整个底栏。
- **日志「拦截统计」域名少首字母**：统计解析用了一个写死的偏移量，比实际标记短一个字符，`tracking.miui.com` 会显示成 `racking.miui.com`。现在按标记实际长度截取。
- **免责声明弹窗标题重复**：弹窗标题与正文首行同时显示「免责声明」。正文首行本来就是加粗的标题，去掉弹窗那一层。

## 内部

结构整理（root 命令收口、注入分发改表、页面状态合并、纯函数断言），行为不变，不需要为此升级。

## 调整

- 「覆盖组件」表改为按能力分类（统计与埋点 / 设备与位置 / 行为记录 / 诊断与反馈 / 运营商侧 / 输入法 / 广告与商店），不再列出包名
- 「拦截层次」按四层重写（采集入口 / 本地存储 / 对外接口 / 网络出口，方法层作兜底），不再写具体 API 与数据库表名
- 「参考来源」保留致谢与项目名，去掉其中的域名与包名细节
- 移除界面预览截图——截图里含组件名与上报地址
- 界面文案收敛两处：路径规则说明不再出现具体路径，行为库状态说明不再出现数据库文件名

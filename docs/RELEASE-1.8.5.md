感谢您使用 HyperPGuard。

这一版在「行为库状态」弹窗里加了「清空行为库」：如果行为库已经堆了很多历史记录，可以一次清掉，让写入计数从零开始。

## 新增

- 「行为库状态」弹窗底部新增「清空行为库」按钮（红色，与「刷新」并排）
- 点击后二次确认，说明会发生什么：停止安全中心进程、删除行为库文件（含 `-wal` / `-shm` / `-journal`）、历史记录不可恢复、安全中心下次启动会重建一个空库
- 只在用户确认后执行；本模块的开关、规则与拦截行为不受影响

## 说明

- 需要 root，与「重启」「查看日志」一致
- 清空后库里暂时没有文件，安全中心会在下一次有行为记录时重建；这段时间「行为库状态」显示「读不到行为库」属正常
- 用途：把写入计数当作「拦截是否生效」的指标时，先清零再对比更直观

感谢您使用 HyperPGuard。

这一版新增两个输入法分组，并修了组件拦截页搜索的一处漏匹配。

## 新增

**微信输入法**（`com.tencent.wetype`）

- 统计埋点：灯塔 `h.trace.qq.com` 与配置 / 灰度下发，默认开
- 崩溃与性能上报：Bugly 与 rmonitor，默认开
- 云输入与词库：微信云与 CDN，**默认关**（会影响云联想、词库同步、皮肤下载）

**豆包输入法**（`com.bytedance.android.doubaoime`）

- 统计埋点：AppLog 埋点域名，默认开
- 配置与校验：配置 / 灰度 / 校验域名，**默认关**
- 云输入服务：输入法服务端，**默认关**

两个分组都遵循既有规则：只停上报的默认开，会影响云输入与配置下发的默认关，副标题写明后果。

## 修复

- 搜索原先只匹配开关名称与描述，分组标题里的词（例如「输入法」）搜不到。现在把分组名与分组说明一起纳入索引，搜「输入法」能命中全部六个输入法分组。

## 说明

- 微信输入法若为 LSPatch 注入版，LSPosed 与 LSPatch 同时注入同一进程存在冲突风险；拦截走的是系统类（`URL` / `InetAddress` / `Socket`）上的域名匹配，方法层失配只记 `miss`，不影响域名层
- 作用域新增两个包，覆盖升级后需到 LSPosed 里确认勾选

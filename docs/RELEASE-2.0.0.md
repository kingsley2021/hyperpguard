感谢您使用 HyperPGuard。

这一版把「能看到什么」补上：主页新增 MiSight 事件库的只读浏览，底栏换了真正的液态玻璃折射。

## 新增

- **MiSight 事件库（只读）**：主页「安全中心行为库」下面新增一行，点开可以看系统行为采集库
  的汇总与明细——事件总量、累计次数、上传记录、最近一次时间、库版本，以及按次数排序的事件列表，
  点条目看首次/最近时间与参数。读取方式是用 root 把 `/data/miuilog/misight/event.db`
  复制到应用缓存后只读打开，查完即删副本，不改原库、不上传、不导出。
- 页面里写清了这个库的作用（记录哪些行为、参数是什么）、数据流向（写入 → 聚合 → 上传），
  以及使用边界（仅本机、仅自己的设备）。

- **开关热重载**（PR #29，感谢 KANGKKKKKKK）：改完开关不用再点「重启」——模块会通过框架让已注入的进程
  换用新配置，只重载受影响的组件。批量行新增「热重载」按钮，「全部启用 / 全部停用」也会自动触发；
  框架不支持或提示失败时，仍用「重启」兜底。

## 调整

- 「行为库状态」改名为「安全中心行为库」，与新的「MiSight 事件库」并排，标题格式统一。
- 底栏胶囊的玻璃效果换成 miuix 的折射 shader（AGSL，`assets/lens_refraction.agsl`）：
  圆角矩形 SDF 在边缘带做位移、七次采样做轻微色散，再加左上高光与底部内阴影。
  需要 Android 13（API 33）以上；更低版本仍用原来的模糊贴图。
- 关于页的「被采集数据」入口撤销，功能移到主页，和另一个库放在一起。

## 说明

- 版本号跨到 2.0.0：界面结构与能力都有新增，不是补丁级改动。
- 事件库的读取需要 root（KernelSU / Magisk）授权；没有授权时页面会直接给出原因。
- 本模块仍然只做本机自查，不协助读取他人设备或账号的数据。

感谢您使用 HyperPGuard。

这一版在组件拦截页顶端加了搜索框：开关一多，翻页找某一项很费劲，现在输两个字就只剩相关的几行。

## 新增

- 组件拦截页标题下新增搜索框：48dp 胶囊、左侧放大镜，输入即时过滤
- 匹配开关的**名称与描述**，不区分大小写
- 未命中的行连同它前面的分隔线一起收起；一张卡片全部未命中时连分组标题一起隐藏，不会留下一排空标题
- 全部未命中时显示「没有匹配的开关」
- 搜索词在深浅色切换后保留，切回来不用重新输

## 说明

- 搜索只影响显示，不改任何开关状态；「全部启用 / 全部停用 / 全部重启」始终在搜索框下方
- 放大镜为 Canvas 绘制，不引入 drawable 资源与第三方库
- 文案已补英文（Search / No matching switches）

感谢您使用 HyperPGuard。

这一版修三处显示与提示问题，并更新使用条款。

## 修复

- **安全中心行为库**：库里还没有行为表时（比如刚清空过、安全中心尚未产生记录），以前直接显示「读取失败」；现在先检查表结构，说明「库里还没有行为表（只有系统元数据）」，不再当成故障。
- **设置页「配置导入导出」**：标题与副标题改成和「查看日志 / 分享日志 / 清理日志缓冲」同款（16sp + 12sp），不再是一行标签加右侧小字。
- **主页与组件页文字对齐**：开关行、分组标题、分组说明统一 4dp 内边距，卡片内文字落在同一条左边线上。

## 条款

- 使用条款更新到 1.18：补充「版本与适用范围」——条款修订号与软件版本号无关，声明适用于所有版本；应用内展示的是当前安装版本内置的条款，仓库 `DISCLAIMER.txt` 是最新版，两者不一致时以仓库为准。
